# Refined Network 0.3.4（历史发行：rswirelesscrafting 0.3.4）

0.3.x 维护线，2026-10-29 发行，不包含 0.4.x 新设备。2026-10-30 仅勘误说明文字，未修改既有二进制、tag、日期或发行状态。

## 本版修复记录

- 修正0.3.3中费用不足时跳过watcher注册、关闭终端后移除未注册watcher导致异常的路径；注册与移除处理改为幂等。
- 打开终端前检查费用，避免进入电量不足的空界面。
- 补充充电站方块网络容器能力，允许网络线缆发现该设备。

以上保留原版修复记录。本轮没有重新构建或重做实机验证，不推导为所有后续版本和相同类别问题均已修复。

## 下载与升级

NeoForge：`rswirelesscrafting-neoforge-0.3.4.jar`；Fabric：`rswirelesscrafting-fabric-0.3.4.jar`。按加载器选择一个文件，需 Minecraft 1.21.1、对应 RS 2 与加载器；Fabric 具体依赖以本发行包元数据为准，检查 Fabric API、Cloth Config API 与 Team Reborn Energy。

原说明称 RS 2.0.9 已测试；本轮未重复该测试，也不据此承诺 RS 2.0.7 之后所有版本兼容。升级前备份世界及配置，在测试世界验证；保留并比较自定义配置，不无条件删除。移出旧JAR避免重复加载。

本次维护保持0.3.3的注册ID和配方引用；这不等于任意存档、未来 modId 迁移或异常数据场景无损保证。

## 限制与反馈

客户端配置显示可能与服务器不同，实际结算以服务端为准。0.3.3退出版记录保留在CHANGELOG，不新增或改写历史版本。

[反馈问题](https://github.com/KokuuWork/refined-network/issues)：请附加载器、本模组和RS版本、步骤、实际 / 预期结果及脱敏日志。
