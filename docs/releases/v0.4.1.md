# Refined Network 0.4.1（历史发行：rswirelesscrafting 0.4.1）

0.4.1 于 2026-10-28 发行，取代已撤下的 0.4.1-beta.1。本页于 2026-10-30 勘误文字；**未替换二进制、移动 tag、更改发布日期或新增历史功能**。

原发布说明报告 NeoForge 已验证终端绑定、无线样板终端、无线能量接收器、能量监控仪显示屏和无线连接器；未逐项验证其余功能及 Fabric。本轮仅复核文案，未重做这些测试，原报告不构成无上限 RS 版本兼容保证。

## 下载与依赖

- NeoForge：`rswirelesscrafting-neoforge-0.4.1.jar`。
- Fabric：`rswirelesscrafting-fabric-0.4.1.jar`。
- 按加载器二选一；Minecraft 1.21.1、对应 RS 2 版本及加载器。原说明列 RS 2.0.7+ 并称测试过 2.0.9；这是原发布记录，不表示更高版本均支持。
- Fabric 依赖以此发行包元数据为准；除 Fabric API 外，应检查 Cloth Config API 与 Team Reborn Energy 是否已安装。饰品支持另需对应 RS 整合。

## 本版记录

新增无线连接器，提供“记录接入点→绑定目标”的设备操作入口；新增能量监控仪的三行悬浮显示：电量、净收支与预计耗尽。

原发布记录中的修正：

- 关闭合成终端的 watcher 注册 / 移除异常，终端打开前费用预检。
- 样板终端虚拟实体存活与激活显示、四终端能量能力。
- 虚拟样板网格和管理器使用真实方块状态，避免 RS 2.0.9 方块实体类型校验异常。
- 方块网络容器能力、桥作为网络接入目标、监控仪邻接网络解析。
- 接收器改为从绑定供电网络取电，经缓冲供给旁边的本地网络。
- 绑定反馈、说明与图标补充。

这些是本版当时记录的修改，不表示当前所有类似问题都已关闭。当前源码需另核对，尤其计费、菜单权限与缓存。

## 用法勘误与升级

连接器普通右键 RS 网络方块记录接入点，再右键支持的设备绑定；记录随后清除。没有源记录时，右键已绑定设备会解绑；有记录时尝试重新绑定。手持连接器潜行右键清除记录。桥作为连接器目标时优先走设备操作；以桥基点配对可先清除旧接入点记录，使用原有裸手潜行入口在未配对基点记录，再对另一座未配对桥完成配对；已配对据点优先解绑。

接收器放在用电网络旁，绑定到供电网络。名义速率受容量、距离和可提取电量限制；不能把“空控制器可由缓冲启动”理解为无电也可运行。

升级前备份世界与配置，移出旧 JAR 后安装新 JAR。由 beta 升级的接收器需核对绑定方向并按需重新绑定；不要求所有用户无条件重放设备。自定义配置与默认值比较后按需迁移，不无条件删除。卸载前处理已配对桥的保活记录。

## 限制

- 客户端配置提示不替代服务端收费规则。
- 跨维访问仍需有效链路、加载、权限及供电；部分桥可按配置主动保活，不能笼统说所有设备都有保活。
- 样板和饰品 / 配方查看工具兼容应按版本组合验证；未全面验证光影或字体资源包。
- 自动补货依赖 RS 在制需求判断，不是绝对单任务或幂等保证。
- `require=0` 不是 Mixin 与未来 RS 版本安全兼容保证。

## English

0.4.1 was published on 2026-10-28 under the historical rswirelesscrafting identity. This text-only correction does not change its binaries, tag, date or original release status. Original notes report limited NeoForge testing; the remaining features and Fabric were not individually verified. No new tests were performed for this correction.

The release added the wireless connector and floating energy display, and recorded fixes to watcher cleanup, virtual pattern menus, item energy capabilities, block network capabilities, target resolution and receiver direction. The receiver draws from its bound supply network and serves the adjacent local network.

Choose one loader-specific JAR and verify its dependencies. Back up saves and configurations; compare custom values rather than deleting them unconditionally. A recorded connector source causes binding / rebinding; without a source, a bound target is unbound. Sneaking with the connector clears the record. Permissions, loaded chunks and energy remain necessary. Original RS 2.0.9 testing claims do not establish support for every later version, shader combination or Mixin target. Current development issues are tracked separately.
