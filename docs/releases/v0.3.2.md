# Refined Network 0.3.2（历史发行：rswirelesscrafting 0.3.2）

0.3.2 于2026-10-15发行，为0.3.1的修复版。原说明将其标为测试阶段，尤其Fabric未完成完整实机验证；本次保留这个历史说明，不更改Release元数据状态。2026-10-30仅纠正文案，不改变二进制、tag、日期或新增历史功能。

## 0.3.2修复记录

- 网络不足时，远程输电先检查余额，再尝试电池路径，修正此前零头扣取后又扣电池的双收费问题。
- 无线充电采样倒数修正为每10 tick一次，按当时配置发放对应充电额度。
- 无线名额提示改为总共3个设备，而非每玩家独立3个。

## 本版继承的0.3.1内容

Fabric移植及可选饰品支持；同维度距离超过16格线性计费，跨维度默认×16；手工合成20 FE、自动合成40 FE，打开 / 清空 / 配方转移5 FE；充电站内部缓冲默认4000 FE与无线名额调整。

当时还记录界面数字和槽位提示修正、旧缓冲容量钳制、装配界面锁定终端所在槽及充电扫描 / 方块状态降频。以上不是本次新增功能，也不能替代当前版本的复验。

## 下载、依赖与升级

- NeoForge：`rswirelesscrafting-neoforge-0.3.2.jar`。
- Fabric：`rswirelesscrafting-fabric-0.3.2.jar`。
- 按加载器选择一个JAR，使用Minecraft 1.21.1、对应RS2和加载器。原说明列RS2.0.7+并报告2.0.9测试；本轮未重复，不能据此承诺全部更高版本兼容。
- Fabric除Fabric API外还需核对发行包对Cloth Config API和Team Reborn Energy的依赖。饰品槽需对应的Curios / Trinkets与RS整合组合。

升级前备份世界和配置，在测试世界验证；比较并按需迁移自定义配置，不因默认值不同直接删除。移出旧JAR避免重复加载。客户端配置提示不能代替服务端结算。本次显示名统一不涉及未来modId迁移。
