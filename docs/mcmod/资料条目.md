# MC百科 资料条目提交包

适用版本：**0.4.1**（Minecraft 1.21.1，NeoForge / Fabric）。
共 20 条资料：终端 4、升级插件 6、方块设备 7、工具 3。

## 文件说明

| 文件 | 用途 |
|---|---|
| `mcmod-items.json` | 批量导入用。**每行一个 JSON**，直接整份贴进站内批量导入 |
| `icons/<注册名>.png` | 64×64 图标（JSON 里已内嵌，此目录供核对或替换） |
| `icons/<注册名>_32.png` | 32×32 小图标 |

## 提交步骤

1. 打开 [批量添加资料 JSON 收纳帖](https://bbs.mcmod.cn/thread-1281-1-1.html)，按帖子格式回帖：模组名称、站内 ID（31918）、模组版本 `0.4.1`、游戏版本 `1.21.1 NeoForge`、导出工具填「手动整理」。
2. 附上 `mcmod-items.json`。每行一条，导入器会按 `I:` 计数。
3. 导入后按类型批量调整：把 7 个方块设备从「方块」改为「机器」（如果站内分类更合适）。
4. 合成表单独提交，用 RecipeDumper 或 IconRenderer 导出，本站格式为 `R:` 行。

## 图标说明

- 物品图标取自模组自带纹理，按最近邻放大到 32 / 64，保持像素风；终端使用「未绑定」状态的外观。
- 方块图标由顶面 / 正面 / 侧面纹理做等轴投影合成，**不是游戏内真实渲染**。若站内审核要求实机渲染图，用 IconRenderer 导出一份替换 `icons/` 下的同名文件即可，JSON 结构不变。
- 图标为 PNG 的 base64，**不带** `data:image/png;base64,` 前缀（站内格式要求）。

## 字段说明

| 字段 | 取值 |
|---|---|
| `registerName` | `rswirelesscrafting:<注册名>`，与游戏内一致 |
| `englishName` | 取 `en_us.json`，未自行翻译 |
| `OredictList` | `[]`，本模组未给这些物品加物品标签 |
| `maxStackSize` | 终端 / 工具为 1，插件与方块为 64（取自 `Item.Properties`） |
| `maxDurability` | `0`，全部无耐久 |

> 1.13+ 格式不含 `metadata` 字段，导入器会忽略旧字段。
