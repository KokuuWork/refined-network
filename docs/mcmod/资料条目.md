## 文案与使用边界

- 显示名更改不替换 `rswirelesscrafting:<注册名>`，也不要求更改旧物品或存档的注册 ID。
- 终端访问仍需对应范围 / 维度插件、可用网络、加载、供电与权限条件，不能写成无条件任何距离、任何维度均可用。
- 无线能量接收器的现行方向是从绑定供电网络取电，经缓冲供给相邻本地网络，并只挂载本地网络；不应沿用旧的「把外部发电并入绑定网络」说明。
- 当前「打开无线合成终端」快捷键只查找无线合成终端与无线样板终端，不包含管理器、监控终端或全部 RS 无线设备。
- 网络桥接器是受限物品 / 能量转发，不是无限完整双网合并；补货依赖 RS 任务判定，不承诺所有情况下绝不重复。光影、字体与 Mixin 组合须实测，不承诺全部兼容或不兼容时自动安全失效。
- 升级前备份配置与存档，比较新旧字段和默认值后按需迁移，按加载器要求重载或重启；不无条件删除配置，不保证跨版本存档绝不丢失。

1. 打开 [批量添加资料 JSON 收纳帖](https://bbs.mcmod.cn/thread-1281-1-1.html)，按帖子格式回帖：模组显示名称「精致网络 / Refined Network」、站内 ID（31918，提交前确认页面更名状态）；核对既有包与目标发行包后，模组版本填 `0.4.1`、游戏版本填 `1.21.1 NeoForge`、导出工具填「手动整理」。Fabric 内容须单独核对并标明加载器；尚未发布的 `0.5.0` 不作为正式发行资料提交。
2. 附上核对后的 `mcmod-items.json`。每行一条，导入器会按 `I:` 计数，不改既有模板语法。
3. 导入后按类型批量调整：把 7 个方块设备从「方块」改为「机器」（如果站内分类更合适）。
4. 合成表单独提交，用目标版本的 RecipeDumper 或 IconRenderer 导出，本站格式为 `R:` 行。

## 图标说明

- 物品图标取自模组自带纹理，按最近邻放大到 32 / 64，保持像素风；终端使用「未绑定」状态的外观。本轮未重新生成，提交前须核对目标版本的外观与名称。
- 方块图标由顶面 / 正面 / 侧面纹理做等轴投影合成，**不是游戏内真实渲染**。若站内审核要求实机渲染图，用 IconRenderer 导出一份替换 `icons/` 下的同名文件即可，JSON 结构不变。
- 图标为 PNG 的 base64，**不带** `data:image/png;base64,` 前缀（站内格式要求）。

## 字段说明

| 字段 | 取值 |
|---|---|
| `registerName` | `rswirelesscrafting:<注册名>`，保持既有注册 ID，不用显示名替换 namespace |
| `englishName` | 既有包取自 `en_us.json`；提交前与目标版本语言文件核对，未自行翻译 |
| `OredictList` | `[]`，保留既有导出字段；空列表不代表物品没有游戏内标签，插件判定标签另行核对 |
| `maxStackSize` | 终端 / 工具为 1，插件与方块为 64（既有包取自 `Item.Properties`，提交前与目标版本核对） |
| `maxDurability` | `0`，既有清单全部无耐久 |

> 1.13+ 格式不含 `metadata` 字段，导入器会忽略旧字段。
